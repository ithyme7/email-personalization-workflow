# Market-Ready Checklist

## Product

- [ ] CSV import handles the client's real columns.
- [ ] Output workbook is readable without explanation.
- [ ] Tone profile is selected per customer.
- [ ] Manual-review rows are clearly visible.
- [ ] Model/provider settings are documented.
- [ ] Sample input and sample output are sanitized.

## Quality

- [ ] No em dashes in generated lines.
- [ ] No unsupported claims.
- [ ] No generic praise.
- [ ] Every sendable line has evidence.
- [ ] Low-confidence visual findings are manually checked.
- [ ] Duplicate company rows are consistent.

## Commercial

- [ ] Clear offer and pricing test.
- [ ] Demo script ready.
- [ ] Calibration batch process ready.
- [ ] Client feedback loop defined.
- [ ] Before/after examples collected.

## Privacy

- [ ] `.env` is not committed.
- [ ] Client CSV files are not committed.
- [ ] Outputs are not committed.
- [ ] Cache and screenshots are not committed.
- [ ] API keys are rotated if exposed.

## Delivery

- [ ] Final workbook checked manually.
- [ ] Weak rows either fixed or marked.
- [ ] Delivery note explains what to review.
- [ ] Follow-up asks for examples of off-tone rows.
