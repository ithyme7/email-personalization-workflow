# Demo Script

## 30-Second Intro

"This workflow turns a lead CSV into an evidence-backed review workbook. It researches public company pages, captures source evidence, selects a friction-first angle, drafts a short opener, and flags weak rows for manual review."

## Demo Flow

1. Show the input CSV.
2. Run the tool or show the run command.
3. Open the Excel workbook.
4. Start with the Dashboard.
5. Move to the Review tab.
6. Show `template_preview`.
7. Show `evidence_found`.
8. Show `quality_flags` and `needs_manual_review`.
9. Open Research Details for one row.
10. Explain how tone profiles change the writing/QC layer.

## Key Talking Points

- The tool is conservative by design.
- The goal is not blind automation.
- Weak evidence is made visible.
- Duplicate companies can reuse personalization.
- The reviewer can quickly edit lines with evidence beside them.

## Good Questions To Ask

- What makes a line unusable for you?
- What tone examples should the system learn from?
- Which sources do you trust most?
- How much manual research should happen before a line is considered sendable?
- What would make this worth using weekly?
